# Next data sources for Hou Match

Checked 2026-09-19 after the map/context PR merged. These are recommendations, not imported data or implemented tools. Reuse the current Supabase project and add small tables; no new database instance is needed. Keep the existing annual profiles and amenities separate from current operational feeds.

HUD is valuable once the workbook is acquired/validated. None requires a decade-wide import. These priorities do not imply that the current frontend's scores or monetary examples are already backed by these sources.

## Exact sources and interpretation

**Census:** [2024 five-year API examples](https://api.census.gov/data/2024/acs/acs5/examples.html), [release status](https://www.census.gov/programs-surveys/acs/news/data-releases/2024/release.html), [free-key instructions](https://www.census.gov/library/video/2026/adrm/requesting-a-census-data-api-key.html). Use `B19013_001E`, `B25077_001E`, `B25064_001E` and their `M` margins of error plus relevant annotations. Preserve missing-estimate codes as unavailable. Houston is state/place `48/35000`; San Francisco city `06/67000`; New York city `36/51000`. Use one matching product/year, not one-year city values against five-year neighborhood values. SF city is not the whole Bay Area. City medians are comparisons, not ingredients for averaging neighborhood medians. The tiny no-key request redirected to `missing_key.html` with HTTP 200 HTML; validate content, not just status. Latest published five-year release verified here is 2020–2024.

**METRO:** [official developer portal](https://api-portal.ridemetro.org/), [official hosted GTFS ZIP](https://metro.resourcespace.com/pages/download.php?ref=4835&ext=zip). The ZIP was 12,660,993 bytes; bounded range reads checked its directory and feed/calendar metadata without downloading all schedules. Edition `August2026IVOMS_20260828` has calendar dates through 2027-02-13 but `feed_info` ends 2027-01-23: treat the earlier date as the validity limit pending reconciliation. Keep service-day/exception semantics, coordinates and accessibility fields where supplied. Retain METRO's attribution: “Route and arrival data provided by permission of METRO.” A nearby stop or scheduled frequency does not establish a candidate's actual commute time or reliability. Realtime arrivals require separate developer signup/key; they are unnecessary for this first transit layer.

**FEMA:** [NFHL Flood Hazard Zones, layer 28](https://hazards.fema.gov/arcgis/rest/services/public/NFHL/MapServer/28) is the newly verified working no-key endpoint. Select `DFIRM_ID`, `FLD_AR_ID`, `FLD_ZONE`, `ZONE_SUBTY`, `SFHA_TF`, `SOURCE_CIT` and geometry. Pair with [FIRM panels, layer 3](https://hazards.fema.gov/arcgis/rest/services/public/NFHL/MapServer/3) and [map revisions, layer 1](https://hazards.fema.gov/arcgis/rest/services/public/NFHL/MapServer/1). [Study metadata](https://hazards.fema.gov/arcgis/rest/services/public/NFHL/MapServer/41) had a Harris database revision of 2026-05-18, but its `INDX_EFFDT` contained sentinel `8888-08-08`; sampled actual panel effective dates included 2007/2014/2017. Reject the sentinel and do not relabel every polygon “2026 effective.” Proposed outputs are covered-area percentages for mapped 1%-chance/0.2%-chance zones and floodway, with coverage/effective provenance. Unknown/unmapped coverage must not be zero risk. This is neighborhood mapping context, not a guarantee about an individual home. The City's [Flood_Hazard service](https://mycity2.houstontx.gov/gisweb01/rest/services/HoustonMap/Flood_Hazard/MapServer) remains a cross-check; inspected metadata did not establish effective dates.

**HUD:** [SAFMR downloads](https://www.huduser.gov/portal/datasets/fmr/smallarea/index.html) list revised FY2026 and FY2027 public workbooks. The [FY2027 notice](https://www.govinfo.gov/content/pkg/FR-2026-09-01/pdf/2026-17891.pdf) makes FY2027 effective October 1, 2026. On September 19, use effective FY2026; FY2027 may be stored separately as upcoming. Direct workbook retrieval encountered an HTTP 202 challenge, so file rows/ZIP coverage are still unverified. The [API alternative](https://www.huduser.gov/portal/dataset/fmr-api.html) requires a registered bearer token and an explicit year. These are program rental benchmarks, not active listings. ZIP geography is not a Super Neighborhood; retain it or use an explicit reviewed crosswalk, never present a ZIP amount as a neighborhood median.

**Tax/payroll references:** the [IRS 2026 release](https://www.irs.gov/newsroom/irs-releases-tax-inflation-adjustments-for-tax-year-2026-including-amendments-from-the-one-big-beautiful-bill) identifies federal annual adjustments. The checked [California FTB page](https://www.ftb.ca.gov/file/personal/tax-calculator-tables-rates.asp) currently presents 2025 final tables; [New York's 2026 withholding page](https://www.tax.ny.gov/bus/wt/rate.htm) is a withholding source, not a substitute for all annual-liability rules. Finish consistent-year state/local/payroll references and tests before displaying take-home results. Implement math in deterministic backend code; Claude explains returned assumptions. No individualized tax calculation has been implemented by this research.

## Useful stretch additions

- **AirNow regional air quality:** the [official FAQ](https://docs.airnowapi.org/faq) recommends the public [`reportingarea.dat`](https://files.airnowtech.org/airnow/today/reportingarea.dat) file for database caching instead of looping through ZIP queries. File access and current modification metadata were verified; Houston rows still need validation. Keep one hourly latest snapshot with observation time, pollutant, AQI/category and expiry. Follow the [data-use guidance](https://docs.airnowapi.org/docs/DataUseGuidelines.pdf). Preliminary reporting-area values are not precise neighborhood exposure or historical health outcomes. Some legacy API services are retiring in fall 2026; avoid building against them.
- **Zillow ZORI/ZHVI:** [research CSVs](https://www.zillow.com/research/data/) can add recent modeled rent/value context; retain latest period and at most 12 months only if the product shows a trend. Check [reuse/attribution terms](https://www.zillowgroup.com/developers/api/public-data/real-estate-metrics/) and [ZORI meaning](https://www.zillow.com/research/methodology-zori-repeat-rent/). Direct retrieval returned 403 in this check; latest period/Houston coverage remain unverified. This is not an available-apartment feed.

Defer 311 services scoring, permit momentum and crime-based ranking until their previously documented completeness, freshness and methodology gaps are resolved. Keep the existing brokerage-report omission rule. More rows do not fix missing semantics or make a source current.
